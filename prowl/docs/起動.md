# Nekodion Backend

> [!NOTE]
> 各設定値は開発メンバーに聞いてください。

## 起動方法

### 準備

1. IntelliJ > 実行 > 構成の編集を開く
2. 新規構成の追加でGradleを選択する

### API

| 項目                | 設定値                                                                                                         |
| ------------------- | -------------------------------------------------------------------------------------------------------------- |
| 実行 > タスクと引数 | `api:bootRun`                                                                                                  |
| Gradleプロジェクト  | `prowl`                                                                                                        |
| 環境変数            | `DB_NAME=nekodion;DB_USERNAME=;DB_PASSWORD=;ISSUER=;AUDIENCE=;GMAIL_STATE_SECRET=;GMAIL_TOKEN_ENCRYPTION_KEY=` |

### Batch

| 項目                | 設定値                                                                                      |
| ------------------- | ------------------------------------------------------------------------------------------- |
| 実行 > タスクと引数 | `batch:bootRun --args='--batch.execute='`                                                   |
| Gradleプロジェクト  | `prowl`                                                                                     |
| 環境変数            | `DB_NAME=nekodion;DB_USERNAME=;DB_PASSWORD=GMAIL_STATE_SECRET=;GMAIL_TOKEN_ENCRYPTION_KEY=` |

- batch.execute

  | バッチ             | 引数       | 備考             |
  | ------------------ | ---------- | ---------------- |
  | Hello Worldバッチ  | HelloWorld | バッチ起動テスト |
  | Gmail Importバッチ | gmail      | 入出金記録バッチ |
