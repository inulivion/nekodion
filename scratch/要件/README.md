# 要件定義

## 入出金

- 現金・口座振込・口座引き落としなど、実際の資産移動を伴う取引を指す。
- クレカ利用については、利用日を入出金日（出金元はクレカ口座）とする。
- 収支の計算に含めるかかどうかを設定できる

### 一覧

- 日付の新しい順に表示

### 詳細

- 振替レコードの場合、振替解除できる
- 振替解除したレコードはもともとのペアとのみ再度振替にできる
  - 片方のレコードが消えていたらその時点で振替復元は不可

### 手動記録・編集

- 入力フォームの初期値は以下の通り。
  - タイプは支出
  - 口座は「なし」（システム上は未分類口座）
  - カテゴリーは食費
  - 計算対象
  - 日付は当日
- 「振替」選択の場合、振替元と振替先の口座を選べる
  - 「なし」から「なし」だけ禁止する
- 取引名を入力しない場合、カテゴリー名を取引名として記録する

### 削除

- Gmailインポートにより自動で記録された入出金の場合、削除不可

## 口座

### 銀行口座

- 入出金自動記録機能をサポート

### クレカ口座

- 締め日を手動で設定できる
- レコードは出金として記録される
- 利用日を出金日とする。
  - 実際のクレカの引き落とし日ではない。

### 手動管理口座

- 入出金自動記録機能をサポートしない
- ユーザーは財布やPayPay、証券口座の残高など、用途に合わせて自由に名前を設定できる
- 口座の初期残高や残高更新ができる
  - このときのレコードはユーザーには表示しない（帳尻レコード）
  - 残高更新の場合、ユーザーの意思では収支計算対象のレコードとして記録できる

### 未分類口座

- 入出金の記録で口座が「なし」の場合に記録される
- 1ユーザーにつき1つ
- ユーザーの画面には表示されない
- ユーザー作成時、「未分類口座」が自動で一つ作成される

## 収支計算

### 収支

- 入出金の合計
- 計上したくない入出金（立て替えなどで一時的に得た収入など）は除外する
- 入出金レコード未分類口座も計算対象とする
  - 収支は口座基準ではなく全体の入出金を集計するため

### 口座残高

- 共通
  - 入出金レコードの合計
  - 計算対象外フラグのレコードでも計算対象とする
    - 収支には影響ないが、実際の資金移動を口座残高に反映する必要があるため
  - 入出金レコードで口座が未指定の場合、いずれの口座残高にも影響しない
- クレカ口座
  - 計算対象かどうかを問わず、マイナス資産として記録される。
  - 翌月の銀行引き落とし日に、銀行口座からクレカ口座への「振替」レコードが実行されることで、未払い金が相殺（リセット）される。

### 総資産

- クレカ口座の未払金（マイナス残高）を含む、全口座残高の合計（純資産）。
- ただし未分類口座は除外する。

## 振替

- 口座間での資金移動
- 月次の計算対象からは外す
- ユーザーからみると１つのレコードとして表示されている
- システム内部では入金と出金の2レコードセットとして扱う
- 振替の解除が可能
- 振替解除した場合、計算対象の入金レコードと出金レコードの２つに分けて表示される
- 既存の明細を振替にすることが可能
  - 例えばNISAの引き落としが5万円あった場合、この明細を振替にして入金先を手動管理口座に設定できる
